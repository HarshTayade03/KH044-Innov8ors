# KH044-Innov8ors

Project scaffold for the KH044 Innov8ors team.

## Project Structure

- `src/project-source-code/` - application source code
- `docs/` - project documentation, architecture diagrams, and supporting materials
- `screenshots/` - project screenshots
- `data/` - project data and data notes

## Getting Started

Install dependencies and run the starter command:

```bash
npm install
npm start
```

The starter command currently confirms that the project scaffold is ready for implementation.
