### Problem statement
Security teams today receive hundreds or thousands of raw vulnerability findings from multiple scanners, threat feeds, and manual reports. These findings arrive in different formats, use inconsistent naming, and often describe the same underlying issue in multiple ways. As a result, analysts must manually normalise the data, identify duplicates, verify whether a finding is genuine, and decide which vulnerabilities to address first.  

You are building an automated vulnerability triage system (VulnTriager) that takes findings from multiple security tools, normalizes them, deduplicates them, validates exploitability, and produces analyst-ready cases with clear prioritization.

#### Expected Capabilities
- Finding normalization
- Duplicate clustering
- Evidence validation
- Severity reasoning
- Exploitability context
- Human approval workflow
Challenge Environment / Constraints: Synthetic findings and controlled lab targets.
Evaluation Focus: Triage accuracy; evidence integrity; prioritization; safety; analyst value.
